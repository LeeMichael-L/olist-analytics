# 指标字典

> 版本：v1（2026-10-12，阶段1结束）
> 每个指标写明定义、计算口径和所用字段。所有指标默认只统计分析窗口内的订单（`dwd_orders.in_analysis_window = 1`，D-016）。
> 状态为"待定"的指标，在对应模块开始时确认口径后更新本文件。

## 1. 通用口径

| 项目 | 口径 | 依据 |
| --- | --- | --- |
| 时间归属 | 按**下单时间** `purchase_ts` 归入日期和月份 | D-016 |
| 分析窗口 | 2017-01-01 至 2018-08-31 | D-016 |
| 买家 | 用 `customer_unique_id` 识别，不用 `customer_id` | 审计 B5 |
| 已送达订单 | `order_status = 'delivered'` 且 `is_status_conflict = 0` | D-015 |
| 金额单位 | 巴西雷亚尔（BRL），不做通胀调整 | |

## 2. 规模指标

| 指标 | 定义 | 计算口径 | 状态 |
| --- | --- | --- | --- |
| **商品交易额**（北极星指标） | 已送达订单的商品金额之和，不含运费，**不等于 Olist 收入** | `SUM(dwd_order_items.price)`，限已送达订单 | 已定义（D-004、D-020） |
| 订单数 | 已送达订单的数量 | `COUNT(DISTINCT order_id)` | 已定义 |
| 买家数 | 有已送达订单的真实买家数 | `COUNT(DISTINCT customer_unique_id)` | 已定义 |
| 人均订单数 | 订单数 ÷ 买家数 | | 已定义 |
| 客单价 | 商品交易额 ÷ 订单数 | | 已定义 |
| 活跃卖家数 | 当期有已送达订单的卖家数 | `COUNT(DISTINCT seller_id)` | 已定义 |
| 运费占比 | 运费合计 ÷ 商品交易额 | `SUM(freight_value) / SUM(price)` | 已定义 |

商品交易额的指标树：**商品交易额 = 买家数 × 人均订单数 × 客单价**。三个因子必须用同一批订单、同一时间窗口计算（D-005）。

## 3. 体验与履约指标

| 指标 | 定义 | 计算口径 | 状态 |
| --- | --- | --- | --- |
| 平均评分 | 有评价订单的平均评分（护栏指标） | `AVG(dwd_order_reviews.review_score)`，每单一个评分 | 已定义（D-013） |
| 差评率 | 评分为 1–2 分的订单占有评价订单的比例 | `AVG(review_score <= 2)` | 已定义 |
| 配送时长 | 下单到买家收货的天数 | `DATEDIFF(delivered_customer_ts, purchase_ts)`，排除对应时间戳异常的订单（D-014） | 已定义 |
| 按时送达率 | 在承诺日期当天或之前送达的订单比例（护栏指标） | `AVG(DATE(delivered_customer_ts) <= estimated_delivery_date)` | 已定义 |
| 延迟天数 | 实际送达比承诺日期晚的天数 | `DATEDIFF(delivered_customer_ts, estimated_delivery_date)`，按时送达为 0 或负数 | 已定义 |
| 卖家发货超时 | 卖家交物流晚于发货截止时间 | `delivered_carrier_ts > shipping_limit_ts` | 待定（模块3确认订单级规则） |

**敏感性分析的默认设置**

| 编号 | 主分析 | 敏感性分析 | 依据 |
| --- | --- | --- | --- |
| S1 | 使用全部有评价订单 | 排除 `is_review_before_delivery = 1` 的评价 | D-021 |
| S2 | 使用 `review_score`（最后一次评分） | 改用 `first_review_score` | D-013 |
| S3 | 卖家评分类分析只用 `is_multi_seller = 0` 的订单 | 包含多卖家订单 | D-017 |

## 4. 买家指标

| 指标 | 定义 | 计算口径 | 状态 |
| --- | --- | --- | --- |
| 复购率 | 在窗口内下过 2 单及以上的买家占全部买家的比例 | 按 `customer_unique_id` 统计订单数 | 待定（模块5确认：是否只计已送达订单） |
| 同期群留存率 | 首购月份相同的买家，在之后各月再次下单的比例 | | 待定（模块5） |

## 5. 卖家与渠道指标

| 指标 | 定义 | 状态 |
| --- | --- | --- |
| 卖家健康度分层 | 按交易额、平均评分、发货超时率等维度分层 | 待定（模块6） |
| 卖家流失 | 截止日前连续 N 天无订单，且观察期足够长 | 待定（模块6，需处理右删失） |
| 线索转化率 | 签约数 ÷ 线索数，按渠道 `origin` 计算 | 待定（模块7） |
| 渠道质量 | 签约后统一观察窗口内的出单率、交易额与评分 | 待定（模块7） |
