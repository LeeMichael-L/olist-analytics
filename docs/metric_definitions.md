# 指标字典

> 版本：v2.2（2026-10-17，写报告时的回头检验：高延误月、缓冲天数、收货不完整、杠杆区间与 GMV 换算）
> 每个指标写明定义、计算口径和所用字段。所有指标默认只统计分析窗口内的订单（`dwd_orders.in_analysis_window = 1`，D-016）。
> 状态为"待定"的指标属于后续阶段，在对应模块开始时确认口径后更新本文件。

| 项目 | 口径 | 依据 |
| --- | --- | --- |
| 时间归属 | 按**下单时间** `purchase_ts` 归入日期和月份 | D-016 |
| 分析窗口 | 2017-01-01 至 2018-08-31 | D-016 |

| 小样本 | 按州、卖家、渠道等细分维度比较时，样本不足的组不参与结论（门槛见各模块） | D-028、D-030 |

## 2. 规模指标

| 指标 | 定义 | 计算口径 | 状态 |
| --- | --- | --- | --- |
| **商品交易额**（北极星指标） | 已送达订单的商品金额之和，不含运费，**不等于 Olist 收入** | `SUM(dwd_order_items.price)`，限已送达订单 | 已定义（D-004、D-020） |
| 订单数 | 已送达订单的数量 | `COUNT(DISTINCT order_id)` | 已定义 |
| 买家数 | 有已送达订单的真实买家数 | `COUNT(DISTINCT customer_unique_id)` | 已定义 |
| 人均订单数 | 订单数 ÷ 买家数 | | 已定义 |
| 客单价 | 商品交易额 ÷ 订单数 | | 已定义 |
| 活跃卖家数 | 当期有已送达订单的卖家数 | `COUNT(DISTINCT seller_id)` | 已定义 |
| 运费占比 | 运费合计 ÷ 商品交易额 | `SUM(freight_value) / SUM(price)` | 已定义 |

商品交易额的指标树：**商品交易额 = 买家数 × 人均订单数 × 客单价**。三个因子必须用同一批订单、同一时间窗口计算（模块1）。

## 3. 体验与履约指标

字段均来自 `dws_order_fulfillment`（一行一单）。

| 指标 | 定义 | 计算口径 | 状态 |
| --- | --- | --- | --- |
| 平均评分 | 有评价订单的平均评分（护栏指标） | `AVG(review_score)`，每单一个评分（多条评价取最后作答的一条） | 已定义（D-013） |
| 差评率 | 评分为 1–2 分的订单占有评价订单的比例 | `AVG(is_bad_review)`；无评价订单为 NULL，不进入分母 | 已定义（D-024） |
| 配送时长 | 下单到买家收货的天数 | `delivery_days = DATEDIFF(delivered_customer_ts, purchase_ts)` | 已定义 |
| 环节时长 | 审核、卖家处理、物流运输三段各自的天数 | `approve_days`、`seller_days`、`transit_days`；按日期计算，结果为负数时记为 NULL | 已定义（D-026） |
| 承诺配送天数 | 下单到承诺送达日的天数 | `delivery_days - delay_days` | 已定义（模块3） |
| 按时送达率 | 在承诺日期当天或之前送达的订单比例（护栏指标） | `1 - AVG(is_late)` | 已定义 |
| 延误 / 延误天数 | 实际送达晚于承诺日期 | `delay_days = DATEDIFF(delivered_customer_ts, estimated_delivery_date)`；`is_late = (delay_days > 0)` | 已定义 |
| 卖家发货超时 | 卖家交给物流的时间晚于发货截止时间 | `is_seller_late`：单卖家订单比较 `delivered_carrier_ts > shipping_limit_ts`；多卖家订单为 NULL | 已定义（D-023） |
| 跨州订单 | 买家与卖家不在同一个州 | `is_cross_state`：只对单卖家订单有值；`is_cross_state_top` 按交易额最大卖家归属，供敏感性分析 | 已定义（D-025） |
| 多件订单 | 一笔订单包含 2 件及以上商品 | `n_items > 1`；再按 `is_multi_seller` 分为同一卖家 / 多个卖家 | 已定义（模块3） |
| 高延误月（原称高峰月） | 月度延误率超过 10% 的月份 | 2017-11、2018-02、2018-03 | 已定义（D-032、D-035） |
| 缓冲天数 | 承诺配送天数比实际配送天数多出的天数，按月平均；决定延误率高低的关键量 | `AVG(delivery_days - delay_days) - AVG(delivery_days)` | 已定义（D-035） |
| 收货前评价 | 满意度问卷发出日期早于实际送达日期的评价（Olist 在送达或承诺送达日到达时发出问卷） | `is_review_before_delivery = 1`（`review_creation_date < DATE(delivered_customer_ts)`） | 已定义（D-021、D-036） |
| 收货不完整（评论） | 差评评论提到缺件或只收到部分商品 | 评论转小写、去重音后，含 `falta/faltando/faltou/faltaram/faltam`，或同时含 `apenas/somente/so` 与 `recebi/veio/chegou/entregaram` 等动词 | 已定义（D-038） |
| 超额差评 | 某组订单的差评数比"按基准组差评率应有的差评数"多出的部分，用于比较不同因素的影响 | `该组有评价订单数 × (该组差评率 − 基准组差评率)` | 已定义（模块3、6） |
| 杠杆可减少差评（区间） | 把某个问题改善到基准水平后，分析期内可减少的差评数；延误相关杠杆的上限按全部评价、下限按收货后评价计算 | 见 `python/s2_impact_sizing.ipynb` | 已定义（D-034、D-036） |
| 差评对应的 GMV | 每条差评对应的下个月 GMV 损失，用于把杠杆换算成 GMV | 卖家 × 月份固定效应回归的系数 × 该卖家月份的下月 GMV ÷ 当月评价数，按差评数加权平均；约 68 BRL | 已定义（D-037） |

| 编号 | 主分析 | 敏感性分析 | 依据 |

## 4. 买家指标

| 指标 | 定义 | 计算口径 | 状态 |
| --- | --- | --- | --- |
| 复购率 | 在 2 个及以上不同日期下过已送达订单的买家，占全部买家的比例 | `COUNT(DISTINCT DATE(purchase_ts)) >= 2`，按 `customer_unique_id` 统计；受右删失影响，为下限估计 | 已定义（D-022） |
| 复购订单 | 下单日期晚于该买家首次购买日期的订单 | `DATE(purchase_ts) > MIN(DATE(purchase_ts)) OVER (PARTITION BY customer_unique_id)` | 已定义（模块5） |
| 首单体验与复购 | 按首单是否延误、首单评分分组的复购率 | 只用 2018-03-01 前首购的买家 | 已定义（D-033） |
| 同期群留存率 | 首购月份相同的买家，在之后各月再次下单的比例 | | 待定（阶段3） |

## 5. 卖家指标

字段来自 `dws_seller`（一行一个卖家）和 `ads_m6_seller_tier`。规模指标含多卖家订单（按商品行归属），体验指标只用单卖家订单（D-029）。

| 指标 | 定义 | 计算口径 | 状态 |
| --- | --- | --- | --- |
| 卖家 GMV | 卖家在有效订单中售出商品的金额之和 | `SUM(price)`，按商品行归属到卖家 | 已定义（D-029） |
| 未延误订单差评率 | 卖家的单卖家、未延误、有评价订单中差评的比例；排除物流因素，反映卖家可控的体验 | `n_ot_bad / n_ot_reviewed` | 已定义（D-030） |
| 卖家发货超时率 | 卖家的单卖家订单中发货超时的比例 | `n_seller_late / n_ship_orders` | 已定义（D-030） |
| 头部卖家 | GMV 排名前 20% 的卖家 | `gmv_rank <= 0.2 × 卖家总数` | 已定义（D-030） |
| 卖家问题类型 | 两个健康指标各自判定：95% 置信区间下限高于平台平均即为该项有问题；组合为健康 / 时效问题 / 体验问题 / 双重问题；未延误有评价订单 < 30 单为"样本不足"。稳健性检验另用精确二项检验 + BH 校正 | `ads_m6_seller_tier.problem_type`、`tier` | 已定义（D-030、D-039） |
| 超额差评 | 卖家实际差评数比"按平台平均水平应有的差评数"多出的部分 | `n_ot_bad - n_ot_reviewed × 平台未延误差评率`；时效问题的间接损害为粗略估算，见模块6 | 已定义（模块6） |
| 在售卖家流失 | 截止日前连续 N 天无订单，且观察期足够长 | | 待定（阶段3，需处理右删失） |

## 6. 卖家获取漏斗指标

字段来自 `dws_seller_funnel`（一行一条营销线索）。激活与健康只对签约满 90 天观察期的签约计算（`is_observable = 1`，D-031）。

| 指标 | 定义 | 计算口径 | 状态 |
| --- | --- | --- | --- |
| 签约率（线索转化率） | 签约数 ÷ 线索数，可按渠道 `origin` 计算 | `AVG(is_won)` | 已定义（D-031） |
| 激活率 | 签约后 90 天内至少有 1 笔有效订单的签约卖家比例 | `AVG(is_activated_90d)`，分母为 `is_observable = 1` 的签约 | 已定义（D-031） |
| 健康率 | 签约后 90 天内至少有 3 笔有效订单（平均每月 1 单）的签约卖家比例 | `AVG(is_healthy_90d)`，分母同上 | 已定义（D-031） |
| 签约卖家流失 | 签约后 90 天内无有效订单 | `is_observable = 1` 且 `is_activated_90d = 0` | 已定义（D-031） |
| 签约卖家低活跃 | 签约后 90 天内有 1~2 笔有效订单 | `n_orders_90d BETWEEN 1 AND 2` | 已定义（D-031） |
| 每千线索健康卖家数 | 衡量渠道综合质量：每 1,000 条线索最终带来的健康卖家数 | `1000 × 签约率 × 健康率` | 已定义（模块7） |
