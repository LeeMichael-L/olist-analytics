## 3. 新增决策

| 编号 | 摘要 |

| D-009 | 使用 MySQL 26.7，脚本兼容 MySQL 8.0 及以上 |
| D-010 | 原始数据按数据集分子文件夹存放 |
| D-011 | CSV 导入关闭反斜杠转义 |
| D-012 | 导入时去除最后一列末尾的 `\r` |

| D-019 | 邮编坐标取平均值 |
| D-020 | 支付金额不一致不做处理，交易额用商品价格 |

## 4. 数据问题与处理

| 问题 | 数量 | 处理 | 对结论的影响 |
| --- | --- | --- | --- |
| 评论正文含换行，文件行数多于记录数 | 3,852 条评论含 5,495 个换行符 | 导入规则正确识别引号内换行 | 无 |
| 反斜杠转义导致静默少导入1行 | 1 行 | D-011 | 已消除 |
| 部分文件为 Windows 换行，末尾残留 `\r` | 2 个文件 | D-012 | 已消除 |
| `review_id` 挂在多个订单上 | 789 个 | 调查确认为同一买家同时下单、共用一份问卷 | 无需处理 |
| 一个订单有多条评价 | 547 个订单，202 个分数不一致 | D-013 | 约 0.2% 的订单，结论对此不敏感 |
| 问卷早于实际送达 | 5,127 条评价（5.3%） | D-021 | 可能影响模块3，须做敏感性分析 |
| 时间顺序违规 | 1,382 单 | D-014 | 只影响对应环节时长 |
| 状态与时间戳矛盾 | 14 单 | D-015 | 可忽略 |
| 一单多卖家 | 1,278 单（1.3%） | D-017 | 影响卖家评分归属，须做敏感性分析 |
| 邮编在地理表中找不到 | 客户 278 个、卖家 7 个 | 坐标记为 NULL | 模块3距离分析中排除，可忽略 |
| 缺失品类或翻译 | 610 个商品无品类；2 个品类无翻译 | D-018 | 无 |

## 5. 局限性

- 评价的生成机制（何时发送、为何重发）Olist 未公开说明，调查结论基于数据推断
- 时间戳违规的原因（时区、记录方式）无法从数据中确认，只能标记
- 本阶段只做了数据层面的检查，尚未涉及任何业务结论
