**主要发现**


1. **平台增长进入平稳期。** 2018年1–8月已送达订单数同比增长140%，但月度规模自2018年起稳定在6,000–7,000单；客单价稳定在约138 BRL，交易额增长几乎全部来自订单数增长。2017年黑色星期五（11月24日）单日订单1,147单，为当月日均的4.7倍。
2. **满意度两极分化，差评不能全部归因于延误。** 已收货订单中好评（4–5分）占78.9%，但评分呈J型分布，9.7%的订单获得最低分。按时送达率为93.2%，即使所有延误订单都给出1分，也无法解释全部1分评价，说明存在延误以外的差评原因。
3. **卖家比买家在地理上更集中。** 59.5%的活跃卖家位于圣保罗州（SP），而该州买家只占41.9%；RJ、BA 等州买家占比明显高于卖家占比，5个州完全没有卖家，大量订单需要跨州运输。这是模块3"跨州配送影响履约和满意度"的待检验假设。
4. **品类结构分散。** 没有单一主导品类（第一名健康美容仅占9.3%），但前10个品类贡献了62.5%的交易额。

## 6. 经验与教训

1. **以后选择图表类型时，我会先问"读者要完成什么任务"**，因为任务决定图表：看趋势用折线图；比较类别用条形图，类别多或名称长时横放并按大小排序；有固定顺序的刻度（如1–5分）用竖向柱状图并按刻度排列；看数值分布用直方图。
2. **以后给图表配色时，我会先想颜色要表达什么含义**，因为颜色会被读者理解为信息：没有好坏之分的类别用同一种颜色；有正负方向的数据（如好评与差评）用两种对比色，中性部分用灰色；需要突出某一项时，用一种强调色配合灰色背景。
3. **以后拿到查询结果，我会先用已知数字检查它是否合理**，因为查询没有报错不等于结果正确。
