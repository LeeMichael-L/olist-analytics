Olist 电商平台运营分析项目

本项目要回答的问题：
  1. 本项目希望分析 Olist 电商平台的运营表现。
  2. 主要回答平台如何在保持交易增长的同时，提高买家满意度和卖家质量。
  3. 通过订单、用户评价和卖家数据，发现影响业务表现的关键因素。

数据来源：
    使用 Kaggle 公开的 Olist Brazilian E-Commerce Dataset。包括Olist Orders Dataset（订单及交易信息）、Olist Reviews Dataset（用户评价信息）
